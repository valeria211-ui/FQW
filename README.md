# DB Performance Benchmark

Учебно-исследовательский проект для сравнительного анализа
производительности PostgreSQL с использованием индексации
и многоуровневого кэширования (Redis).

## Цель проекта
Исследовать влияние индексации и кэширования на время отклика
и пропускную способность SQL-запросов.

## Технологии
- Python (Flask)
- PostgreSQL
- Redis
- Docker
