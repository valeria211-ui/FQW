### 🔹 load_test.py
**Модуль эмуляции нагрузки (ядро эксперимента).**

Функции:
- Имитация параллельной работы множества пользователей
- Параллельное выполнение SQL-запросов
- Замер времени выполнения запросов
- Расчёт пропускной способности (QPS)
- Передача метрик в базу данных

Данный файл реализует экспериментальную часть дипломной работы.

---

### 🔹 db.py
**Модуль работы с базой данных PostgreSQL.**

Назначение:
- Централизованное управление подключением к БД
- Исключение дублирования кода подключения
- Упрощение масштабирования и поддержки

Содержит:
- Функцию получения соединения с PostgreSQL
- Общие настройки подключения

---

### 🔹 queries.py
**Набор тестовых SQL-запросов.**

Назначение:
- Хранение заранее подготовленных SQL-запросов
- Используется в нагрузочном тестировании
- Позволяет легко изменять и сравнивать поведение разных запросов

Запросы включают:
- JOIN между несколькими таблицами
- Агрегации
- Фильтрацию по популярным ("горячим") данным

---

## 📊 Метрики производительности

В процессе выполнения нагрузочных тестов собираются следующие показатели:
- `duration_ms` — время выполнения запроса (мс)
- `qps_metric` — количество запросов в секунду (QPS)
- `scenario_type` — тип сценария эксперимента
- `query_name` — идентификатор запроса

Метрики сохраняются в таблицу `metrics` базы данных PostgreSQL и используются
для дальнейшего анализа и визуализации.
